# AiraLang Language Support for VS Code

Official Visual Studio Code extension for **AiraLang** — the modern systems, AI, and cybersecurity programming language created by **Adam Eehan (Founder & CEO, Aira Group of Technology)**.
*Code the Higher Tomorrow.*

## ✨ Features
* **Syntax Highlighting (v1.1.0):** Complete token colorization for `.aira` files (`say`, `let`, `fn`, `import`, `from`, `@airaai` / `@aira` directives, modules, operators, comments).
* **Language Configuration:** Auto-closing brackets, braces, strings, and `#` / `//` comment toggling.
* **Intelligent Snippets:** Instant scaffolding for `say`, `let`, `fn`, `import "ai"`, `import "system"`, `import "android"`, and `@airaai`.

## 🚀 How to Install (.vsix)
1. In VS Code, open the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`).
2. Click the **`...`** (More Actions) menu at the top-right of the Extensions panel.
3. Select **"Install from VSIX..."**.
4. Choose `airalang-1.1.0.vsix` and click Install.
